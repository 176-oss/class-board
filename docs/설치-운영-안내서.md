# 학급 디지털 게시판 설치·운영 안내서 (선생님용)

입력 화면: https://176-oss.github.io/class-board/admin.html
학급 PC가 여는 표시 화면: https://176-oss.github.io/class-board/index.html?f=파일ID (입력 화면의 '학급 PC 연결' 탭에 내 주소가 나옵니다)

'확인 필요'라고 적힌 부분은 아직 실제 학급 PC에서 시험하지 않은 내용입니다. 적힌 확인 방법대로 한 번 해 보고 결과를 개발 담당에게 알려 주세요.

## 1. 구글 클라우드 설정 (처음 한 번만)

1. https://console.cloud.google.com 에 게시판을 관리할 구글 계정으로 들어갑니다.
2. 기존 OAuth 클라이언트가 있는 프로젝트를 고릅니다. **클라이언트 ID는 새로 만들거나 바꾸지 않습니다.** 바꾸면 그동안 만든 게시판 파일을 입력 화면에서 열 수 없게 됩니다.
3. 'Google 인증 플랫폼(OAuth 동의 화면) > 데이터 액세스'에서 범위 두 개가 들어 있는지 봅니다. 없으면 추가합니다.
   - `.../auth/drive.file` (이 앱이 만든 파일만 다룸)
   - `.../auth/drive.appdata` (앱 전용 숨김 폴더)
4. 같은 화면의 '대상'에서 게시 상태가 '프로덕션(게시됨)'인지 봅니다. '테스트'로 두면 등록한 테스트 사용자만 로그인됩니다.
5. **별도 프로젝트**를 하나 새로 만듭니다 (표시 화면용 키를 로그인 프로젝트와 섞지 않기 위해서입니다).
6. 새 프로젝트에서 'API 및 서비스 > 라이브러리'로 가서 Google Drive API를 '사용'으로 켭니다.
7. 'API 및 서비스 > 사용자 인증 정보 > 사용자 인증 정보 만들기 > API 키'로 키를 만듭니다.
8. 만든 키를 눌러 제한을 겁니다.
   - 애플리케이션 제한: '웹사이트', 항목에 `https://176-oss.github.io/*` 하나만.
   - API 제한: '키 제한'을 고르고 Google Drive API 하나만.
9. 키를 저장소의 `config.js`에 있는 `DRIVE_API_KEY = ''` 따옴표 안에 넣습니다.
10. `sw.js`의 `VERSION` 숫자를 하나 올리고 함께 커밋해 배포합니다 (올리지 않으면 학급 PC가 예전 설정을 계속 씁니다).
11. 표시 화면에 '설정이 필요합니다. config.js에 DRIVE_API_KEY를 넣어 주세요'가 보이면 9~10번이 아직 배포되지 않은 것입니다.

## 2. 첫 게시판 만들기

1. 입력 화면을 열고 [구글 로그인]을 누릅니다. 학교 계정이 막히면 개인 구글 계정으로 로그인합니다.
2. 학급 이름(예: 3학년 2반)을 넣고 [새 게시판 만들기]를 누릅니다. 링크 공유까지 확인되면 만들기가 끝납니다.
3. 안내, 시간표, 일정, 청소당번, 디자인 탭을 채우고 [저장]을 누릅니다.
4. '학급 PC 연결' 탭에서 [표시 화면 미리보기]로 표시 화면이 잘 나오는지 봅니다.

## 3. 학급 PC 설치

**수동 설치가 기본입니다.** 학교 PC는 내려받은 `.bat` 파일이나 PowerShell이 막혀 있는 경우가 많습니다. 설치 파일은 보조 방법입니다.

### 3-1. 수동 설치 (기본)

1. 입력 화면 '학급 PC 연결' 탭에서 브라우저(크롬 또는 엣지)를 고르고 [명령줄 복사]를 누릅니다. 학급 PC에서 입력 화면을 열 수 없으면, 복사한 명령줄을 메일이나 메모로 옮겨 둡니다.
2. 학급 PC에서 Win+R을 누르고 `shell:startup` 을 입력합니다.
3. 열린 폴더 빈 곳에서 오른쪽 클릭 > 새로 만들기 > 바로 가기.
4. 항목 위치에 복사한 명령줄을 붙여 넣고 이름을 ClassBoard 로 합니다.
5. PC를 다시 켜서 게시판이 열리는지 봅니다. 끄려면 Alt+F4.

알아 둘 것
- 명령줄의 `--user-data-dir=%LOCALAPPDATA%\ClassBoard`는 게시판 전용 프로필입니다. 선생님이 크롬을 이미 열어 두었어도 게시판이 따로 전체 화면으로 열리고, 다른 사이트 기록과 섞이지 않습니다.
- 크롬이 `C:\Program Files\Google\Chrome\Application\chrome.exe`가 아닌 곳에 있으면 명령줄 앞쪽 따옴표 안의 경로를 고칩니다. 크롬 바로가기를 오른쪽 클릭 > 속성 > '대상'에서 실제 경로를 볼 수 있습니다.
- 수동 설치는 켜자마자 열립니다. 네트워크가 늦게 붙으면 잠깐 '연결 중'이 보였다가 저절로 이어집니다.
- **확인 필요: `%LOCALAPPDATA%`가 바로가기 안에서 펼쳐지는지.** 확인 방법: 설치 뒤 게시판이 한 번 열린 다음, 파일 탐색기 주소창에 `%LOCALAPPDATA%\ClassBoard`를 넣어 폴더가 생겼는지 봅니다. 폴더가 없고 `%LOCALAPPDATA%`라는 이름의 폴더가 엉뚱한 곳에 생겼다면, 명령줄의 그 부분을 `C:\Users\<사용자 이름>\AppData\Local\ClassBoard`로 바꿔 씁니다.

### 3-2. 설치 파일 (보조)

1. '학급 PC 연결' 탭에서 [설치 파일 받기]를 누르고 `ClassBoard-install.bat`으로 저장합니다. 브라우저가 저장 창을 열지 못하면 화면에 내용이 나옵니다. [내용 복사] 후 메모장에 붙여 넣고, 파일 > 다른 이름으로 저장에서 파일 형식 '모든 파일', 인코딩 'UTF-8'(BOM 포함이 아닌 것)을 고르고 이름을 `ClassBoard-install.bat`으로 저장합니다.
2. 학급 PC에서 그 파일을 두 번 누릅니다. Windows가 '알 수 없는 앱' 경고를 보이면 학교 규정을 따릅니다. 막혀 있으면 수동 설치로 합니다.
3. 파일이 하는 일: 크롬을 레지스트리(App Paths), Program Files, Program Files (x86), 사용자 폴더 순으로 찾고, 없으면 엣지를 찾습니다. 시작프로그램과 바탕화면에 ClassBoard 바로가기를 만들고, 만들어졌는지 확인합니다. 시작프로그램 바로가기는 켠 뒤 25초 기다렸다가 게시판을 엽니다 (네트워크가 붙을 시간).
4. 마지막에 '설치했습니다'가 보이면 끝입니다. '수동 설치 방법을 따르세요'가 보이면 그 앞 문장이 이유입니다 (브라우저를 찾지 못함, 또는 PowerShell이 막혀 바로가기를 만들지 못함). 3-1로 설치합니다.
5. 지울 때는 [제거 파일 받기]로 받은 `ClassBoard-uninstall.bat`을 실행합니다. 바로가기를 지우고, 보관 내용(`%LOCALAPPDATA%\ClassBoard`)도 지울지 Y/N으로 묻습니다. 게시판 창을 먼저 닫고 실행합니다.

### 3-3. 키오스크 모드 주의

- '키오스크 모드'를 켜면 주소창과 창 단추가 없는 화면이 됩니다. 학생 손이 닿는 PC에서 학생이 다른 화면으로 가지 못하게 할 때만 씁니다.
- **끄는 방법은 Alt+F4입니다.** 선생님과 담당 학생이 반드시 알고 있어야 합니다. 키보드를 치워 두는 경우에도 끄는 방법을 PC 근처에 적어 둡니다.
- 학생 손이 닿지 않는 PC라면 키오스크 모드 없이(전체 화면) 쓰는 것이 관리하기 쉽습니다.

### 3-4. 아직 확인하지 않은 것

| 항목 | 확인 방법 |
|---|---|
| 실제 학급 PC 설치 (수동, 설치 파일) | 3-1, 3-2를 학급 PC에서 한 번씩 해 보고 바탕화면·시작프로그램 폴더(`shell:startup`)에 ClassBoard가 생겼는지 봅니다 |
| 부팅 후 자동 실행 | PC를 완전히 껐다 켜고 로그인 뒤 1분 안에 게시판이 전체 화면으로 열리는지 봅니다 (설치 파일로 설치했다면 약 25초 뒤) |
| 엣지 옵션 동작 | 엣지 명령줄로 설치한 뒤 전체 화면, 키오스크, 복원 말풍선 숨김이 크롬과 같게 되는지 봅니다 |
| `%LOCALAPPDATA%` 펼쳐짐 | 3-1 '알아 둘 것'의 확인 방법 |

## 4. 전원 옵션 (화면이 꺼지지 않게)

1. 설정 > 시스템 > 전원 및 절전으로 갑니다.
2. '화면'의 '전원 사용 시 다음 시간 이후에 끄기'를 '안 함'으로 합니다.
3. '절전'의 '전원 사용 시 다음 시간 이후에 PC를 절전 상태로 전환'을 '안 함'으로 합니다.
4. 학교 관리 프로그램이 전원 설정을 되돌리면 정보 담당 선생님께 예외를 요청합니다.

## 5. 시계, 자동 로그인, 초기화 프로그램

1. 시간 동기화: 설정 > 시간 및 언어 > 날짜 및 시간 > [지금 동기화]. '자동으로 시간 설정'을 켜 둡니다. 시계가 틀리면 오늘 시간표·일정이 어긋나고 표시 화면에 '이 PC의 시계를 확인하세요'가 뜹니다.
2. 자동 로그인: 켤 때 Windows 로그인 화면에서 멈추면 시작프로그램이 실행되지 않습니다. 학교 규정이 허용하면 자동 로그인을 설정하고, 허용하지 않으면 아침에 로그인만 해 주면 게시판이 열립니다.
3. 재시작 때 PC를 처음 상태로 되돌리는 프로그램(복원 프로그램)을 쓰는 PC라면 아래 두 곳을 예외(보존)로 둡니다. 예외가 없으면 켤 때마다 바로가기와 보관 내용이 사라집니다.
   - `%LOCALAPPDATA%\ClassBoard` (게시판 전용 프로필과 보관 내용)
   - 시작프로그램의 `ClassBoard.lnk` (`shell:startup` 폴더), 설치 파일을 썼다면 `%LOCALAPPDATA%\ClassBoardLauncher`도

## 6. 문제 해결

| 화면에 보이는 것 | 뜻 | 할 일 |
|---|---|---|
| 가운데 '연결 중' | 아직 한 번도 내용을 받지 못함 | 인터넷 연결을 봅니다. 30초, 60초, 그 뒤 5분마다 저절로 다시 시도합니다 |
| 가운데 '주소 오류' | 주소의 파일 ID가 틀렸거나, 공유가 끊겼거나, 게시판이 삭제됨 | 입력 화면 '학급 PC 연결'의 주소와 바로가기 명령줄의 주소가 같은지, '공유 중'인지 봅니다. 다르면 3-1을 다시 합니다 |
| 오른쪽 아래 '마지막 갱신 14:05' | 10분 넘게 새 내용을 확인하지 못함 (보이는 내용은 그 시각 것) | 인터넷 연결을 봅니다. 연결되면 저절로 사라집니다 |
| 오른쪽 아래 '며칠째 갱신되지 않음' | 하루 넘게 확인하지 못함 | 인터넷 연결, 공유 상태, API 키 설정(1절)을 봅니다 |
| '이 PC의 시계를 확인하세요' | 이 PC 시계가 저장 시각보다 5분 넘게 늦음 | 5절 1번 시간 동기화 |
| '화면 업데이트 필요' | 게시판 파일이 이 화면보다 새 버전 | 저절로 새 화면을 받습니다. 하루가 지나도 남으면 Alt+F4로 끄고 다시 엽니다 |
| '연결 설정을 확인하세요' | API 키가 막힘 | 1절 8번 키 제한(웹사이트 주소, Drive API)을 봅니다 |
| 입력 화면 '이 계정은 링크 공유가 허용되지 않습니다' | 학교(기관) 계정이 외부 링크 공유를 막음 | 개인 구글 계정으로 로그인해 게시판을 만듭니다 |
| 켤 때 '복원하시겠습니까' 말풍선 | 지난번에 전원이 그냥 꺼짐 | 명령줄의 `--hide-crash-restore-bubble`을 `--disable-session-crashed-bubble`로 바꿔 시험합니다 (확인 필요: 크롬 버전에 따라 다름) |

## 7. 개인정보 주의, 공유 끊기와 삭제

1. **이름·연락처 같은 개인정보는 쓰지 마세요. 링크를 아는 사람은 누구나 볼 수 있습니다.**
2. 학생 얼굴이 나온 사진은 올리지 않습니다. 청소당번은 번호로 두는 것이 안전합니다.
3. 주소가 밖으로 퍼졌다고 생각되면 바로 '학급 PC 연결'의 [지금 공유 끊기]를 누릅니다. 학급 PC는 잠시 뒤 '주소 오류'로 바뀌고 보관 내용을 지웁니다.
4. 다시 쓰려면 새 게시판을 만들고(새 주소) 학급 PC 바로가기를 새 주소로 바꿉니다.
5. 학년이 끝나면 [게시판 삭제]로 게시판 파일, 이미지, 이전 버전을 드라이브에서 지웁니다. 학급 PC에서는 `ClassBoard-uninstall.bat` 또는 바로가기 삭제와 `%LOCALAPPDATA%\ClassBoard` 폴더 삭제로 정리합니다.

## 8. 선생님이 학교를 옮길 때 (인수인계)

게시판 파일은 만든 선생님의 구글 드라이브에 있습니다. 다음 선생님이 이어서 쓰려면 두 가지 중 하나를 고릅니다. (가) 내 드라이브에서 게시판 파일(`board-...json`)과 이미지 파일을 다음 선생님에게 공유하고 '소유자로 지정'으로 소유권을 넘깁니다 (같은 종류의 계정끼리만 됩니다. 넘긴 뒤 다음 선생님이 입력 화면에서 열리는지 함께 확인합니다). (나) 넘길 수 없으면 다음 선생님이 새 게시판을 만들고, 학급 PC 바로가기의 주소를 새 주소로 바꿉니다 (3-1을 다시 하거나, 바로가기 속성 > 대상에서 `?f=` 뒤를 바꿈). 어느 쪽이든 끝나면 이전 선생님은 자기 쪽 게시판의 공유를 끊거나 삭제합니다.
